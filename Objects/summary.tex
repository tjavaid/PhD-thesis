The requirements on all objects used in the analysis (with 2018 data) are summed up in the Table~\ref{tab:objsummary}. In addition, a ``ghost-cleaning'' procedure is applied to the muons, as described in Sec.~\ref{sec:muonReco}. 

A lepton is declared {\bf loose} if it passes the reconstruction, kinematics and dxy/dz cuts and declared {\bf tight} if it passes in addition the identification, isolation and SIP3D cut. 

For 2016 and 2017 overall selections are same except a few as given below:   

\begin{itemize}    \label{differences}
	\item For 2018 and also for 2017, BDT includes ID and as well as Isolation requirements; however, for 2016 BDT includes only ID and cut based Isolation is explicitly applied on the top of BDT.
	\item In 2017 and 2018, \emph{DeepCSV} is used as B-tagging algorithm. For 2016, \emph{CSVv2} was used as B-tagging algorithm (with chosen working point as \\ \verb=pfCombinedInclusiveSecondaryVertexV2BJetTags= discriminator should be greater than 0.8484) %\footnote{In 2016, jet pileup ID is not applied (to be included in upcoming manuscript on the same subject.)
